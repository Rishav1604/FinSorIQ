
# FinSorIQ

### AI-Powered Corporate Credit Risk Assessment Platform

FinSorIQ is an educational fintech application designed
to assist corporate credit analysts with financial
statement analysis, credit risk assessment and
indicative credit rating.

## Core Features

- Annual report intelligence
- Financial data extraction
- Financial ratio analysis
- Historical financial performance analysis
- Corporate credit risk assessment
- Probability of Default modelling
- Peer comparison
- Market intelligence
- Indicative credit rating
- Automated PDF and Excel reports

## Technology Stack

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Scikit-learn
- Git and GitHub

## Project Status

Currently under development.

## Disclaimer

FinSorIQ is an educational and analytical project.
Its indicative assessments are not official credit
ratings issued by registered credit rating agencies.
